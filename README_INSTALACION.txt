NUESTRA DISCOTECA FAMILIAR - INSTALACION

Esta carpeta es una PWA. Para que la camara en directo funcione debe publicarse en una direccion HTTPS; no basta con abrir index.html directamente.

Opcion sencilla de publicacion:
1. Descomprime el ZIP.
2. Sube el contenido de la carpeta (no la carpeta contenedora) a un alojamiento estatico con HTTPS, por ejemplo GitHub Pages, Netlify o Cloudflare Pages.
3. Abre la URL HTTPS resultante desde el movil.
4. Concede permiso para usar la camara.
5. Android/Chrome: menu de tres puntos > Instalar aplicacion o Anadir a pantalla de inicio.
6. iPhone/Safari: boton Compartir > Anadir a pantalla de inicio > Anadir.

El lector analiza continuamente el video. No hay que hacer una foto ni pulsar un disparador: al leer dos veces seguidas el mismo EAN/UPC, detiene la camara y busca la edicion.
